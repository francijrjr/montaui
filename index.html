Monta UI Começando Instalação CLI

Instalação & Configuração CLI

Aprenda a configurar seu projeto React com Tailwind CSS e utilizar o Monta CLI para gerenciar componentes.

1 Criar um projeto React (Vite / Next.js)

Crie um novo projeto React com TypeScript e Tailwind CSS:

# Usando Vite com TypeScript
pnpm create vite meu-app --template react-ts
cd meu-app

2 Instalar Dependências Essenciais

Instale os pacotes fundamentais para manipulação de classes e ícones:

pnpm add clsx tailwind-merge class-variance-authority lucide-react

3 Inicializar o Monta CLI

Execute o assistente de inicialização para gerar o arquivo components.json:

pnpm dlx monta-ui init

O arquivo components.json gerado terá a seguinte estrutura:

{
  "$schema": "https://monta-ui.dev/schema.json",
  "style": "default",
  "rsc": false,
  "tsx": true,
  "tailwind": {
    "config": "tailwind.config.js",
    "css": "src/globals.css",
    "baseColor": "slate",
    "cssVariables": true
  },
  "aliases": {
    "components": "@/components",
    "utils": "@/lib/utils",
    "ui": "@/components/monta-ui"
  }
}

4 Criar Utilitário src/lib/utils.ts

Este helper une clsx e tailwind-merge para mesclagem limpa de classes Tailwind:

import { clsx, type ClassValue } from "clsx"
import { twMerge } from "tailwind-merge"

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs))
}

5 Adicionar Componentes com o CLI

Agora você pode instalar qualquer componente do catálogo instantaneamente:

# Adicionar múltiplos componentes
pnpm dlx monta-ui add button dialog input table badge
